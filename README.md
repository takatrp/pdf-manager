# PDFマネージャー r36

ブラウザ内でPDFを編集する静的Webアプリです。既存の個別ツールに加え、読み込んだPDFを続けて編集する作業画面を追加しています。

## 主な変更

- 結合・ページ追加・回転・削除・並び替えを1つの作業内で続け、最後に保存
- 直近50操作の「元に戻す」「やり直す」。保存後も編集を継続
- 日本語メモ、確認済／要確認印、チェック、ページ番号
- 保存するPDFそのもののページ別プレビューとページ数・ファイル名確認
- 画像化圧縮で解像度を変更しても用紙サイズが変わらないよう修正（回転、CropBox、UserUnitを考慮）
- 文字を残す構造最適化を既定に。画像化は明示選択。小さくならなければ元のバイト列で保存
- 署名欄があるPDFは構造最適化でも書き換えず、元データを保存
- 機能切替時の古い状況表示、ファイル名全文表示のラベル、入力ラベル、広い画面のレイアウトを改善
- PDF内容の端末内処理とGoogle Analyticsのアクセス解析通信を分けて説明

## 大切な制限

- 元ファイルは上書きしません。作業はタブのメモリ内にあり、閉じる・再読み込みで失われます
- メモ等は画像として重ねます。元の文字は残り、機密情報を除去する墨消しには使えません
- 編集画面の書き出しでは、署名・フォーム・しおり等の文書機能は保持を保証しません。元ファイルを保管し、出力を確認してください
- 画像化圧縮は検索・コピー・フォーム・リンク・電子署名などを失います
- 構造最適化は画質を下げませんが、大幅な圧縮を保証しません
- OCR・Word変換は今回の対象外です
- 新しい本番用外部サービス／ライブラリCDNは追加していません。日本語メモは端末の日本語フォントで描画されます

## ローカルで開く

Node.js 22以上で、このディレクトリから実行します。

```sh
npm ci
npm start
```

http://127.0.0.1:4173/pdf-manager/ を開いてください。HTMLをfile://で直接開く方法はモジュール読込のため推奨しません。

## 検証

```sh
npm run build
npm run test:node
npx playwright install chromium
npm test
```

インストール済みChromiumを使う場合は PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH を指定できます。

- `test:node`: 編集状態と実際のPDF出力、PDF.js→canvas→JPEG→PDFの圧縮、注釈の描画と寸法、元文字の検索性、共有リソース維持を検証
- `npm test`: 既存機能、新しい作業画面、圧縮、通信／CSPのブラウザ回帰テスト
- `@napi-rs/canvas` は検証専用の開発依存で、公開ページには配信しません
- Node描画テストの合成PDFとPNGは `artifacts/` に出力します

## 今回の検証状況

Nodeの状態／実出力描画テスト、非ブラウザ圧縮テスト、静的セキュリティチェック、ビルド検証は通過しました。日本語の出力PNGも目視確認しています。

実ブラウザの自動テストは、この作業環境でChromiumのプロセス用ソケット作成が拒否され、起動前に停止しました。別のクラウドブラウザでもlocalhostへのアクセスがブロックされたため、画面レイアウト、実際のダイアログ／ダウンロード、スマートフォン幅の動作は未検証です。公開前に利用可能なブラウザ環境で `npm test` と最終画面確認を実施してください。
